# Pricing Model

## Overview

MEDITSIIN4.0 operates on a **subscription-based pricing model** where organizations (GP centers) subscribe based on the **number of workplaces** they need to support.

Customers receive a **single, unified bill** for their subscription, with the flexibility to choose the number of workplaces and whether each workplace includes hardware (computer) or is software-only (teams access).

---

## Core Model: Per-Workplace Subscription

Organizations pay a monthly or annual subscription fee based on the number of workplaces they require.

### Definition of "Workplace"

A workplace is a designated work position that requires access to MEDITSIIN4.0 services. Each workplace can be configured in two ways:

1. **Workplace with Computer (Full Workplace)**
   - Includes hardware (laptop/computer)
   - Includes all software tools and services
   - Ideal for: On-site workstations, positions needing dedicated hardware

2. **Workplace without Computer (Software-Only/Teams Access)**
   - Software access only (no hardware included)
   - All digital tools and services included
   - Ideal for: Remote workers using their own devices, positions that already have hardware

**Key Benefits:**
- Predictable, scalable pricing
- Single unified bill for easy budgeting and accounting
- Flexibility to mix hardware and software-only workplaces based on needs
- Simple for medical centers to understand and manage
- Supports both on-site and remote work models

## Pricing Structure

### Base Pricing Components

Customers configure their subscription by selecting:
- **Number of workplaces** (total count)
- **Workplace type mix:**
  - X workplaces with computers (hardware + software)
  - Y workplaces without computers (software-only)

**Single Bill Structure:**
All components appear on one unified invoice:
- Workplace subscriptions (with/without computers)
- Additional hardware items (if needed)
- Any add-on services
- All clearly itemized on the same bill

## Pricing Considerations

### Volume Discounts
Consider offering discounts for:
- Larger numbers of workplaces (e.g., 10+ workplaces get X% discount)
- Higher percentage of workplaces with computers
- Annual vs monthly billing
- Multi-location agreements

### Configuration Flexibility
Customers can:
- Start with software-only workplaces and add computers later
- Mix workplace types based on actual needs
- Scale up or down by adjusting workplace count
- Change workplace type mix as needs evolve

### Startup/Onboarding Fees
- **Option A:** One-time setup fee for initial deployment
- **Option B:** Setup included in first month/annual subscription
- **Option C:** Free setup for certain tiers or contract lengths

## Pricing Rationale

### Why Per-Workplace Model?

**Advantages:**
1. **Simpler for customers:** Easy to understand - count your workplaces, choose computer or not
2. **Single bill:** One invoice covers everything, easier accounting
3. **Flexibility:** Mix of hardware and software-only based on actual needs
4. **Supports remote work:** Software-only option for remote workers using own devices
5. **Better value perception:** Organizations see value per workstation/position
6. **Scalability:** Easy to add workplaces as organizations grow or needs change

**Customer Benefits:**
- Pay only for what you need
- Easy to understand pricing structure
- Flexible configuration options
- Single point of billing
- Can adapt as workforce model changes (more remote, more on-site, etc.)
